# Web Security Notes

This repository contains my personal notes and hands-on learning from web security topics including PortSwigger labs, TryHackMe, and bug bounty practice.

It includes:
- Core web fundamentals
- Common web vulnerabilities
- Payloads and attack techniques
- Lab writeups
- Tools and methodology notes

## Purpose
This repo is used to:
- Document my learning while solving security labs
- Summarize key concepts in web vulnerabilities
- Keep reusable payloads and techniques
- Build a structured knowledge base for bug bounty practice

## Structure
- fundamentals → HTTP, sessions, authentication basics
- vulnerabilities → common web attacks (XSS, SQLi, IDOR, etc.)
- tools → Burp Suite, Nmap, FFUF usage notes
- labs → PortSwigger, TryHackMe, DVWA writeups
- payloads → useful attack payloads
- bug-bounty → methodology and recon process
- scripts → simple automation tools
